# Qattice Explorer

Open `index.html` in a browser to explore the dashboard. It uses the original design image as its visual base, with keyboard-accessible controls for search, blocks, transactions, validators, and network details. Press Ctrl+K or Cmd+K to search.

The dashboard and drill-down records are a devnet sample snapshot. No live node endpoint is configured. On narrow screens, scroll horizontally to view the full dashboard.
