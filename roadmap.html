Where we are today

Phase 0 foundational acceptance is complete. Security hardening and signing-v2 integration are being validated in draft pull requests. Four-node signing-v2 tests have passed, but this is not a PQ-HotStuff network. PQ-HotStuff, public testnet and mainnet remain future milestones.

Status describes engineering evidence, not public availability. Draft changes are not automatically merged or deployed.

0

Blockchain Foundation

Foundational acceptance complete

Core chain infrastructure, wallet and identity foundations, transaction execution, cryptographic validation and private multi-node testing.

Security hardening and integration work continue beyond the original Phase 0 closeout.

1

Security & PQ-HotStuff Integration

Current / upcoming

Complete signing-v2 integration and hardening. Implement PQ-HotStuff safety rules, quorum certificates, validator membership and reliable recovery.

Exit gate: independently reproducible private-network consensus and security evidence.

2

Private PQ-HotStuff Testnet

Planned

Operate a controlled multi-node network using PQ-HotStuff with identity-backed validator rules and post-quantum signatures.

Exit gate: verified finality, safety, state-root agreement, restart and network-recovery testing.

3

Public Testnet Alpha

Planned · not authorized

Invite early users, developers and validator testers to try wallets, test transactions, public APIs and the Explorer under published participation rules.

Testnet tokens have no promised value. Testnet data and balances may be reset. Access policy will be announced before launch.

4

Public Testnet Beta

Planned

Broaden participation and test validator onboarding, proof-of-personhood, wallet recovery, governance and performance under realistic load.

Exit gate: published security, reliability and operational readiness criteria.

5

Mainnet Genesis

Future milestone

Launch the production sovereign network with approved validator, identity and monetary parameters, including the planned $QCB and $QRC roles.

Requires independent security review, finalized genesis configuration, operational readiness and explicit launch authorization. Features are only live when individually released.

6

Ecosystem Expansion

Long-term vision

Expand developer applications, merchant payments, Digital Identity Stone authorization, Charmed Agents and verified useful computation through PoCD.

Each capability has its own implementation and production acceptance gates; not all are expected at genesis.
